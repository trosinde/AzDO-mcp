# Sicherheitsrichtlinie

Schwachstellen bitte vertraulich über
[GitHub Security Advisories](https://github.com/trosinde/AzDO-mcp/security/advisories/new)
melden («Report a vulnerability»). Bitte kein öffentliches Issue anlegen.

Bitte keine echten PATs, Server-URLs oder Kundendaten in die Meldung kopieren; Platzhalter genügen.

Du bekommst eine Antwort, sobald der Maintainer die Meldung geprüft hat.
