MCP-Clients einbinden

Der Client startet azdo-mcp.exe --stdio. PATs bleiben im Benutzerprofil, in keiner Client-Konfiguration.

Claude Code

eingerichtet
claude mcp add azure-devops -- ^
  "%LOCALAPPDATA%\AzdoMcp\current\azdo-mcp.exe" --stdio

Claude Desktop

offen
"azure-devops": {
  "command": "…\\AzdoMcp\\azdo-mcp.exe",
  "args": ["--stdio"] }

OpenCode

eingerichtet
"azure-devops": { "type": "local",
  "command": ["…\\azdo-mcp.exe", "--stdio"] }

VS Code / GitHub Copilot

offen
"servers": { "azure-devops": { "type": "stdio",
  "command": "…\\azdo-mcp.exe", "args": ["--stdio"] } }
Programm Pfad bleibt nach Updates gleich. Beim Eintragen wird eine Sicherung der Client-Konfiguration angelegt.
